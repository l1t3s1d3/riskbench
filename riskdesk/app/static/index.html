Wiz file import
Upload a Wiz vulnerability export (JSON). Accepts the format from Wiz Reports, the GraphQL query builder output, or a raw {"findings": [...]} array. This bypasses the live API and lets you validate schema mapping before configuring the connector.
Historical remediation import
Backload remediated findings from a CSV so prior remediation history is reportable. Required columns: canonical_id, source, asset, severity, first_detected, closed_at, status. Optional: cve_id, title, category, component, component_version, source_finding_id, asset_type. status is one of fixed / verified_fixed / stale / suppressed_at_source. Dates in ISO 8601 (2026-04-12 or 2026-04-12T15:00:00Z).
